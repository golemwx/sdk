## 自审与修复

- 目录创建从 `MkdirAll(root/parent)` 改为先创建根目录，再由 `os.Root.MkdirAll` 创建父目录，
  避免在创建父目录时穿过指向根目录外的符号链接。
- 只读路径不调用任何 `MkdirAll`；Remove 同样保持惰性。
- Windows 无符号链接权限时，测试使用目录 junction 验证真实逃逸拒绝，而不是跳过。
- 删除 R03/R04/R05 遗留的 `unsupportedData` 占位实现，避免数据 API 仍返回
  `Unimplemented`。
