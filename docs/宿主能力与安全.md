# 宿主能力与安全

## 权限

所有 Host 回调都经过宿主授权；缺少权限时默认拒绝。插件不能通过请求体中的自报身份绕过
实例绑定。权限覆盖消息、联系人、群、标签、收藏、朋友圈、小程序、公众号、支付、用户、
CDN、登录、会话租约、能力调用和自身配置，实际可用范围由 frame 的插件策略决定。

插件应把 `PermissionDenied` 当作终态错误，不通过重试或换目标绕过。权限错误不会因为
插件是 Owner 自动放开；敏感写操作需要显式授权。

以下权限属于显式授权集，默认不随插件声明自动授予：

| 域 | 权限 |
| --- | --- |
| 原始消息 | `message.raw` |
| 联系人管理 | `contact.manage` |
| 群管理 | `chatroom.manage` |
| 标签 | `label.read`、`label.write` |
| 收藏 | `favorite.read`、`favorite.write` |
| 朋友圈 | `moments.read`、`moments.write` |
| 小程序 | `miniapp.use` |
| 公众号 | `official.read`、`official.write` |
| 支付与红包 | `payment.use` |
| 当前用户 | `user.read`、`user.write` |
| CDN | `cdn.use` |
| 登录生命周期 | `login.manage` |

`message.raw` 不得由 `message.send` 或 `message.read` 推导。原始应用 XML、core 消息 ID、
直接撤回、语音直接下载和转写只对显式获得该权限的插件开放。

## Host.Core

`Host.Core` 声明当前 golem-core 的全部公开业务 API，共 123 个类型化方法：

- 119 个普通 core 路由
- 4 个宿主登录会话入口：`login.start`、`login.status`、`login.cancel`、`login.logout`

子客户端按联系人、群、消息、收藏、CDN、标签、小程序、朋友圈、公众号、支付和用户分组。
插件不得拼接 core HTTP 路径，也不得访问 `github.com/golemwx/core` 的 DTO、服务或私有字段。
`/api/message/sync` 继续使用 `Events.Subscribe`，不建立第二条事件流。

资源边界：

- 请求 JSON 最多 4 MiB，响应 JSON 最多 16 MiB，直接提交的小程序协议 JSON 最多 256 KiB
- SDK gRPC 一元消息上限为 20 MiB，只为容纳 core 大结果和 protobuf 开销
- CDN 上传结果返回绑定账号、实例、种类和期限的 `coreapi.ResourceRef`，不返回文件 ID 或 AES 密钥
- core 下载结果转换为宿主 `MediaRef`；插件转发和再次发送时继续使用不透明引用
- 小程序头像随机/上传结果只保留串联设置头像所需的 `file_key`，其他私有字段不公开
- Cookie、Authorization、ticket/token、A8/A2/AES 密钥、验证 URL/token、原始 XML 和 CDN 私有 ID 不进入插件可见 JSON

调用规则：

- 登录状态与账号状态可在离线时查询；其他 core 业务方法要求账号在线
- 未知方法、无路由方法或当前 core 不存在有效入口时返回 `NotFound`/`Unimplemented`，不返回空成功
- 写请求已提交但响应丢失、超时或取消时为 `OutcomeUnknown`，不得自动重试
- 上游明确拒绝且可确认没有完成目标写入时为 `OutcomeFailed`；响应损坏或结果无法验证通常为 `Internal`
- `ResourceRef` 或 `MediaRef` 跨账号、跨实例、种类不符返回 `PermissionDenied`，过期返回 `FailedPrecondition`

## 配置

SDK 只定义配置快照、修订和保存结果类型，不直接读取宿主文件。frame 负责：

- 读取并校验 `plugins/config.toml`
- 维护 desired/active revision
- 把已接纳快照传给插件
- 在 CAS 保存成功后原子替换配置

插件只能通过 Host 配置接口保存自己的业务子节，不能写入其他插件或宿主私有字段。

## 资料与路径

插件运行目录由 frame 设置为 `plugins/data/<id>/`，Host.DataDir 提供同一路径。插件不应
假定当前工作目录是仓库根目录，也不应读取 `golem-core/data`。媒体临时文件和宿主引用由
frame 管理，插件只持有不透明句柄。

## context 与资源

- 业务回调使用当前调用 context，保留宿主签发的身份、期限和取消。
- 后台任务使用启用周期 `TaskContext`，禁用或卸载后必须停止。
- `Drain` 后不再接收新工作；超过硬截止时插件进程可能被终止。
- 卸载或断连后旧 Host 句柄不可用，不能仅用 nil 判断可用性。

## 错误与副作用

跨进程错误使用 `*sdk.Error`，调用方按 `Category` 和写操作的 `Outcome` 判断。未实现方法
返回 `CategoryUnimplemented`，不能返回空成功。`OutcomeUnknown` 的写操作不得自动重试，
避免重复发送或重复副作用。
