# 快速开始

SDK 是插件与 frame 之间的公共契约。插件只依赖 SDK，不导入 frame 或
`github.com/golemwx/core`。

## 环境

- Go 1.27.3
- Task 3.54.0
- 普通公开开发不需要 core 源码或私有凭据

## 创建插件模块

每个插件使用独立 module，例如：

```powershell
New-Item -ItemType Directory example-plugin
Set-Location example-plugin
$env:GOWORK = "off"
$env:GOFLAGS = ""
go mod init github.com/example/example-plugin
go get github.com/golemwx/sdk@v0.0.0-20261029033730-7a6331800673
```

入口调用 `plugin.Serve`，需要宿主能力时嵌入零值 `plugin.Base`：

```go
type implementation struct {
    plugin.Base
}

func main() {
    plugin.Serve(&implementation{})
}
```

SDK 会在反向连接初始化后、`OnLoad` 之前自动绑定 `p.Host`。不要在构造期读取或改写
Host；业务回调必须使用调用 context。

## 本地检查

在插件 module 目录执行：

```powershell
$env:GOWORK = "off"
$env:GOFLAGS = ""
go mod tidy -diff
go test -count=1 ./...
go vet ./...
go build -trimpath -o build/golem_plugin_example.exe .
```

Windows 使用 `.exe`；Linux/macOS 去掉扩展名。

插件可执行文件名和目录规则由 frame 决定，示例和部署说明见
[golem-plugins](https://github.com/golemwx/plugins)。

## SDK 仓库开发

```powershell
task proto
task test
task lint
task build
```

`task proto` 固定 Buf 和 protoc 插件版本，生成后会在临时目录重复生成并核对字节差异。
正式命令固定 `GOWORK=off GOFLAGS=`；本地 workspace 只用于联调，不能代替独立依赖构建。
