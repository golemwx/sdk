# 快速开始

## R02 能做什么

R02 提供可编译的公共模型和通信契约。它不提供插件进程入口、Kong 命令执行、
配置读写、数据目录实现或日志桥接。不要用本修订声称插件已经可以启动。

| 能力 | R02 状态 |
| --- | --- |
| Message、SendResult、事件、订阅、选择器、Host 签名 | 已冻结 |
| Proto 服务、oneof、手写转换和契约测试 | 已交付 |
| Runtime 生产实现、插件进程和单实例锁 | R03 |
| Kong 结构体命令、lexer、validator | R04 |
| Config[T] 注入、校验、保存和回调 | R05 |
| 懒创建插件数据目录 | R06 |
| slog 与 go-plugin 日志桥接 | R07 |

## 环境

- Go 1.27.3
- Task 3.54.0（仅用于仓库任务；也可直接执行 `go` 命令）
- 不需要 core 源码、微信账号或外部数据库

## 编译期最小示例

创建一个独立 module，例如 `github.com/example/example-plugin`，加入以下包：

```go
package example

import (
	"context"

	"github.com/golemwx/sdk/event"
	"github.com/golemwx/sdk/plugin"
)

type Plugin struct {
	*plugin.Base
}

func New() *Plugin {
	return &Plugin{Base: plugin.NewBase()}
}

func (*Plugin) Metadata() plugin.Metadata {
	return plugin.Metadata{
		ID:          "example",
		Name:        "示例",
		Description: "R02 编译期契约示例",
		Version:     "0.0.0",
	}
}

func (*Plugin) Subscriptions() []event.Subscription {
	return []event.Subscription{{Topic: event.Message, Mode: event.Observe}}
}

func (*Plugin) OnEvent(context.Context, event.Event) (event.Result, error) {
	return event.Result{}, nil
}
```

它可以通过 `go test ./...` 编译，但没有 `main` 和 `plugin.Serve`。R03 才会增加
真实进程入口；下游不应自行编造启动函数或反向 Host 连接。

需要 SDK 依赖时，使用 GOLEM-39 正文登记并验证过的 R02 仓库提交；本仓库不伪造
已发布 tag 或伪版本。上级 `go.work` 只用于本地联调，正式验证应隔离 workspace。

## 本地检查

```powershell
$env:GOWORK = "off"
$env:GOFLAGS = ""
go test -count=1 ./...
go vet ./...
$env:CGO_ENABLED = "0"
go build ./...
```

SDK 仓库本身可执行：

```powershell
task proto
task test
task lint
task build
```
