## 最小插件

创建一个独立 module，例如 `github.com/example/example-plugin`，加入 `main.go`：

```go
package main

import (
	"context"

	"github.com/golemwx/sdk/event"
	"github.com/golemwx/sdk/plugin"
)

type Plugin struct {
	*plugin.Base
}

func New() *Plugin {
	return &Plugin{Base: plugin.NewBase()}
}

func (*Plugin) Metadata() plugin.Metadata {
	return plugin.Metadata{
		ID:          "example",
		Name:        "示例",
		Description: "R03 最小插件示例",
		Version:     "0.0.0",
	}
}

func (*Plugin) Subscriptions() []event.Subscription {
	return []event.Subscription{{Topic: event.Message, Mode: event.Observe}}
}

func (*Plugin) OnEvent(context.Context, event.Event) (event.Result, error) {
	return event.Result{}, nil
}

func main() {
	plugin.Serve(New())
}
```

构建后的可执行文件由 frame 启动。SDK 在 go-plugin 握手和任何业务回调前取得
`<安装根目录>/run/plugin-example.lock` 的 OS 排他锁；同一安装目录中的同 ID 进程只能有
一个持有者。锁文件可以长期存在，进程退出后由操作系统释放锁。

## 配置

插件匿名嵌入 `*plugin.Config[T]` 后，SDK 自动上报默认 TOML、接收宿主配置、严格解码、
执行标签和业务校验，并在命令中串行保存和发布：

```go
type Config struct {
	Threshold int  `toml:"threshold" validate:"min=2,max=10"`
	Enabled   bool `toml:"enabled"`
}

type Plugin struct {
	*plugin.Base
	*plugin.Config[Config]
}

func New() *Plugin {
	return &Plugin{
		Base:   plugin.NewBase(),
		Config: plugin.NewConfig(Config{Threshold: 2, Enabled: true}),
	}
}

type Commands struct {
	Threshold ThresholdCommand `cmd:"" name:"threshold" scope:"owner" help:"设置阈值"`
}

type ThresholdCommand struct {
	Value int `name:"value" required:""`
}

func (*Plugin) Commands() any {
	return &Commands{}
}

func (c ThresholdCommand) Run(ctx context.Context, p *Plugin) error {
	return p.Config.Update(ctx, func(next *Config) error {
		next.Threshold = c.Value
		return nil
	})
}
```

写命令必须声明 `scope:"owner"`。`Update` 只修改隔离候选值，校验通过并等待 frame 确认
落盘后才发布；保存失败或校验失败保持旧值，普通配置更新不重启插件进程。需要重建运行
资源的插件可实现 `OnConfigChanged(ctx, previous, next)`。首次生成的零值配置不合法时
插件进入待配置状态，只有 owner 命令可以修复。

## frame 启动与收尾

frame 使用同一个公开 `plugin.Client` 完成 Describe 和 Initialize，不启动第二个校验进程：

```go
client, err := plugin.Start(ctx, plugin.ClientOptions{
	Command:  exec.Command(pluginPath),
	PluginID: "example",
	Host:     host,
	DataRoot: dataRoot,
})
if err != nil {
	return err
}
defer client.Close()

descriptor := client.Descriptor()
_ = descriptor

if err := client.Load(ctx); err != nil {
	return err
}
if err := client.Start(ctx); err != nil {
	return err
}

// 即使 Stop 返回错误，也必须继续 Unload/确认退出，不能直接启动替代进程。
stopErr := client.Stop(stopCtx)
unloadErr := client.Unload(unloadCtx)
if !client.Exited() {
	return fmt.Errorf("plugin exit is not confirmed: %w", unloadErr)
}
return errors.Join(stopErr, unloadErr)
```

真实 frame 必须按[插件通信](插件通信.md)的 R10 退出确认协议管理锁、PID 和替代进程，
不能仅按进程名终止进程。

需要 SDK 依赖时，使用 GOLEM-39/GOLEM-40 正文登记并验证过的仓库提交；本仓库不伪造
已发布 tag 或伪版本。上级 `go.work` 只用于本地联调，正式验证应隔离 workspace。
