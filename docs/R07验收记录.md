## 自审与修复

- 修正原项目桥接思路中的等级判断和字段处理：SDK 按 hclog 阈值映射 slog 等级，不使用会误判
  Info/Warn 的简单 `Is*` 组合。
- 修复 group 前缀会把可信 `plugin_id` 一并分组的问题：保留字段始终注入顶层。
- 插件侧与宿主侧都清理 `plugin_id`、`plugin_name`、`timestamp`、hclog 元字段，防止伪造和重复
  时间戳。
- 增加 SyncStdout/SyncStderr 适配，未结构化输出不再被默认丢弃；stdout 误写以 Error 标记。
- 删除未使用的动态 LevelVar 路径，宿主级别完全由传入的 slog handler 决定。
- 子进程夹具覆盖身份伪造、嵌套 group 和握手期/运行期未结构化 stderr。
