## 修复

- 宿主授权代码返回新 context 时，强制保留原 RPC 的取消及更早截止时间，同时保留授权值
- 排队等待的生命周期调用在取得控制锁后重新检查取消，防止超时请求随后仍执行副作用
- 拒绝超出 Go `time.Duration` 范围的合法 Proto 时长，覆盖 RetryAfter 和租约续期
- 保留业务错误旁的有效发送回执；损坏回执或错误详情保持 Internal、OutcomeUnknown，原始 context 错误保留类别
- 拒绝分页、批量、阶段列表的缺失条目和批量成功项缺失值；失败项忽略不可信 Value，避免清空已有资料
- 校验已知账号状态的 username 和 Online 一致性；未知枚举仍归一 Unknown 并保留其他可用字段
- 生成检查失败时先执行临时目录清理再退出；空生成目录不能构成一致性伪通过
- 启动握手错误转换成公开 SDK 错误，不直接返回子进程握手输出；非法 ID 与标识不匹配分别返回 InvalidArgument、FailedPrecondition

## 简化

- 删除重复错误包装、已被前置检查覆盖的分支和无实际作用的单项 errors.Join
- 发送与回复共用回执解析，避免两条路径对错误和部分结果的处理分叉
- 使用标准库 maps.Clone 复制命名参数，移除手写复制函数
- 固定 ASCII 标识直接检查字节，避免每次启动重复编译正则
- 补齐全部手写函数的中文注释；语法树引用检查未发现未使用的私有函数

业务公开类型、待接入能力的明确 Unimplemented 和生成的 wire 方法属于必要契约，未作为无用代码删除。

## T08 审阅与字段注释统一（2026-10-27）

### 修复

- OnEnable 忽略取消时，启用 RPC 结束等待后后台周期原先仍存活；现在取消尚未提交的
  TaskContext，同时继续保留真正运行中的执行记录，迟到返回不能打开业务准入；取消句柄
  绑定本轮 context，迟到的取消回调不能撤销重新启用的新周期
- 宿主 Authorize 返回已经取消或过期的 context 时，原来只检查请求 context；现在额外检查
  授权后的 context，拒绝进入宿主业务，并保持 Canceled/DeadlineExceeded 类别
- 能力 handler 返回业务错误和超限结果时，原先大小检查会覆盖原错误；现在丢弃超限结果，
  优先保留原错误的 Category、Operation、InvocationID 和 Outcome
- panic 脱敏原先统一写入 plugin.control；现在保留实际事件、命令、能力或控制操作名

### 简化与规范

- 删除与实例控制 context 重复的 initialized 状态，减少初始化与失效状态的重复维护
- 将能力内联上限集中到 internal/transport，rpc 常量和插件 wrapper 共用同一值
- 将剩余手写空接口写法统一为 any，不增加额外包装层或依赖
- 全部手写 Go 结构体和四份 Proto message 字段使用不重复字段名的行尾注释；字段声明
  超过 80 字符时保留上方注释，嵌入字段分组避免 gofmt 产生过长对齐
- Proto 生成文件通过固定 task proto 链更新；字段类型、编号、RPC 和握手配置保持原契约
- 语法树检查覆盖 294 个手写结构体字段和 335 个函数，没有注释规则违规，也没有发现
  缺少引用的私有函数候选；公共 API 和待接入媒体方法是必要契约，予以保留
