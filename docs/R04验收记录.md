## 2. 自审与修复

- 将 owner 预检查从“扫描全部 token”收敛到命令路径前缀，避免业务文本恰好等于 owner
  根命令时误拒绝。
- owner scope 向后代命令继承，frame 只读 selected 节点也不会漏判。
- 修复无枚举参数被生成 `[""]` 的错误 schema。
- 删除 `Call` 中未被消费的字段，合并重复 Kong 构造逻辑。
- 修正校验字段名解析、`gtfield`/`ltfield` 中文原因和 nil 校验目标处理。
- help 使用 Kong 默认帮助模型渲染，但只调用 Trace/PrintUsage，不调用 Parse、Run 或 Exit。
- `--` 终止符之后的 `--help`/`-h` 作为业务位置参数，不再误触发帮助。
- 插件声明 `--help` 或 `-h` 时在加载阶段拒绝，避免产生无法触达的命令参数。
- 增加完整 schema 快照，覆盖命令、别名、scope、参数类型、默认值和枚举。
