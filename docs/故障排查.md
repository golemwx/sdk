# 故障排查

| 现象 | 处理 |
| --- | --- |
| `updates to go.sum needed` | 在 SDK module 执行 `GOWORK=off GOFLAGS= go mod download` 和 `go mod tidy` |
| `missing go.sum entry` | 依赖尚未整理或远端不可达；确认代理/网络后重试，不要伪造校验和 |
| 本地 workspace 能过、正式构建失败 | 正式命令必须 `GOWORK=off GOFLAGS=`；检查 module 自身 `go.mod`/`go.sum` |
| Proto 生成结果不一致 | 使用 `task proto` 的固定 Buf/protoc 插件版本；不要手工改生成文件 |
| `plugin.Serve` 后 Host 为 nil | Host 只在反向就绪后、OnLoad 前绑定；不要在构造期读取，正式启动使用零值 Base |
| Host 调用返回 `PermissionDenied` | 检查 frame 的插件权限和 scope，不要通过重试绕过 |
| `Download`/`Forward` 返回 `Unimplemented` | 当前 core 没有等价业务入口；这是已登记能力缺口 |
| `go test -race` 失败 | race 需要 CGO 和 C 编译器；无 GCC 时记录未验证，不能写成通过 |
| 生成后提交混入构建文件 | 检查 `.gitignore`，只提交 Proto 和预期生成文件，不提交 build/、临时文件或 workspace |

SDK 不读取 core 的配置、会话或设备数据。真实微信和模型服务调用需要单独授权；本地测试
应使用人工 typed 样本和临时目录。
