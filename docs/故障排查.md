# 故障排查

| 现象 | 处理 |
| --- | --- |
| `updates to go.sum needed` | 在 SDK module 执行 `go mod download`、`go mod tidy`，确认网络和校验和可用 |
| 本地 workspace 能过、独立 module 失败 | 使用 `GOWORK=off GOFLAGS=` 重新测试；检查是否误用了 `go.work` 中的其他模块 |
| Proto 生成结果不一致 | 使用 `task proto` 的固定 Buf/protoc 版本；不要手改生成文件 |
| `Message data type does not match message type` | `Message.Type` 必须与八类 Data 一一对应；解析失败时 Data 为 nil，但保留 Content/Raw |
| `timestamp is required` | 消息和事件时间必须是非零合法时间；时间范围错误同样返回 InvalidArgument |
| `duration must not be negative` | 媒体时长必须非负且在 `time.Duration`/Proto Duration 范围内 |
| `SendResult.Revocable()` 为 false | 当前 core 撤回需要成功结果、非零 NewID、数值 ClientID、接收方和创建时间；字符串媒体 ID 或不完整视频回执不能强转 |
| 联系人选择器报 InvalidArgument | 检查空值、未知前缀、`::` 后空值；支持无前缀、`username::`、`nickname::`、`remark::` |
| `another plugin instance is already running` | 同一安装目录和插件 ID 已有进程持有 OS 锁；先按 R10 协议确认旧进程退出，不能删除锁文件当作释放 |
| 插件启动后立刻退出 | 检查安装目录与插件 ID 推导出的 `run/plugin-<id>.lock`、`GOLEM_PLUGIN_INSTALL_DIR` 和 `GOLEM_PLUGIN_LOCK_PATH` |
| `plugin host is not enabled` | 实例已 Stop；Host 调用只能在启用周期内进行。需要重启时调用 Start 建立新周期 |
| 断连后事件返回 FailedPrecondition | 反向 Host 连接已失效，实例被永久标记为不可用；按 R10 停旧进程并重新启动 |
| `plugin.Config.Update` 返回 Unimplemented | R05 才实现配置注入和保存 |
| `Host.Data` 返回 Unimplemented | R06 才实现惰性目录和路径边界 |
| `Unload` 返回错误但 `Exited()` 为 true | 进程已经退出并释放锁，错误来自 OnUnload 或 RPC；仍应按协议记录并核验退出证据 |
| `Unload` 返回错误且 `Exited()` 为 false | 不得启动同 ID 替代进程；先按已确认 PID/启动身份终止并确认退出和锁释放 |
| `go test -race` 失败 | race 需要 CGO 和 C 编译器；没有 GCC 时记录未验证，不能写成通过 |
| 生成后出现空包目录 | 只保留实际 Go 文件；空旧目录不应进入交付 |

SDK 不读取 core 的配置、会话或设备数据。真实微信、CDN 和模型服务验证必须由
有权限的任务单独执行并保留实际证据。
